# Night Eagle

A dark VS Code theme for late-night coding, based on [Night Owl](https://github.com/sdras/night-owl-vscode-theme) by Sarah Drasner.

Night Owl is a well-loved theme, but it is no longer maintained, and newer VS Code releases have started to break parts of it. Night Eagle keeps the familiar Night Owl look and updates it for current versions of VS Code.

## What's different from Night Owl

- The active editor tab is highlighted again in VS Code's new tab design.
- Color settings that VS Code has renamed or removed have been updated, so nothing silently falls back to default colors.
- One focused variant: the dark theme with italics.

## Installation

1. Open the Extensions view in VS Code (`Cmd+Shift+X` on macOS, `Ctrl+Shift+X` on Windows/Linux).
2. Search for **Night Eagle** and click **Install**.
3. Open the Command Palette (`Cmd+Shift+P` / `Ctrl+Shift+P`), run **Preferences: Color Theme** and choose **Night Eagle**.
